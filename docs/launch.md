# 無料公開の手順

期間を決めた無料公開のための、順番どおりの作業手順です。
アプリ側の準備(全体の上限、期限の表示)はコードに入っています。ここに残っているのは、Miso-P さんの手でしか進められないものです。

期限は `lib/constants.js` の `FREE_UNTIL` に入っています。実際の公開日が決まったら、この1行を直してください(いまは仮に `2026年10月31日`)。

---

## 1. 費用に蓋をする(公開前に必ず)

**ここを飛ばして公開しないでください。** 人が集まるほど請求が伸びる構造なので、二重に蓋をします。

### 1-1. Anthropic のクレジット上限

platform.claude.com の **Billing** で:

- **自動チャージ(Auto-reload)をオフ** にする
- クレジットを **$20 程度だけ** 入れる

これが最後の砦です。使い切ると候補の生成が止まりますが、それ以上は請求されません。

### 1-2. アプリ全体の1日上限

`lib/constants.js` の `GLOBAL_DAILY_LIMIT` で設定します(初期値 150回)。

| 1日の上限 | 1日の原価 | 30日で |
| --- | --- | --- |
| 50回 | 約105円 | 約3,150円 |
| 100回 | 約210円 | 約6,300円 |
| **150回**(初期値) | 約315円 | 約9,500円 |

1回あたりの原価は実測 **約2.1円** です(claude-sonnet-5、150円/$換算)。
上限に達すると「本日はたくさんの方にご利用いただいたため、受付を終了しました」と表示され、日付が変わると戻ります。

> 予算に合わせて、この数字だけを変えてください。1-1 の $20 に対して 150回/日だと、フル稼働なら10日ほどで尽きる計算になります。

### 1-3. Supabase の無料枠

Supabase は無料プランのままで足ります。ただし **7日間まったくアクセスが無いとプロジェクトが一時停止** します。公開中は問題になりませんが、公開後に放置する場合は注意してください。

---

## 2. 独自ドメインを取る

先に取ってください。**告知したあとに URL を変えると、共有されたリンクが無駄になります。**

### 2-1. 取得

スマホから完結します。お名前.com、Cloudflare Registrar、Google Domains 後継の Squarespace Domains などで、`.com` や `.app` が年1,000〜2,000円程度です。

ドメイン名は短く、読んで意味が分かるものが向いています(例:`iinikui.com`、`honne-app.com`)。

### 2-2. Vercel に登録

1. Vercel のプロジェクトを開き、URL の末尾に **`/settings/domains`** を足して直接開く
2. 取得したドメインを入力して **Add**
3. 表示された DNS レコード(A レコードまたは CNAME)を、ドメインを買った業者の管理画面に登録する
4. 反映まで数分〜数時間。Vercel の画面が **Valid Configuration** になれば完了

### 2-3. 3か所を書き換える

ドメインが有効になったら、忘れずに:

- **`lib/constants.js` の `SITE_URL`** — シェアボタンが指す URL
- **Supabase の Authentication → URL Configuration** — `Site URL` と `Redirect URLs`(`https://新しいドメイン/**`)。ここを直さないとログインとパスワード再設定が壊れます
- **メール文面の日本語化** — ドメインを認証すれば `docs/email-templates.md` が使えるようになります(Resend なら無料枠3,000通/月)

## 3. 公開前の最終確認

スマホの Chrome で、上から順に。**シークレットタブ**で試すと、初めて来た人と同じ状態を確認できます。

- [ ] `/` を開くと紹介ページが出て、「◯月◯日まで無料で使えます」が表示される
- [ ] 「無料ではじめる」→ 新規登録できる
- [ ] 上司を登録できる
- [ ] 候補が3案出る。冒頭に「送る前にご自身で読み直してください」が出ている
- [ ] 「この言い方を使った(結果はあとで記録する)」→ ホームに「結果待ち」が出る
- [ ] 結果待ちの「使った言い方を見る ▼」で文面が開く
- [ ] 3択を押すと実績が増える
- [ ] 同じ上司に3回相談すると、実績ベースの予測に切り替わる
- [ ] `/privacy` と `/terms` が開き、運営者名と連絡先が出ている
- [ ] 「パスワードを忘れた方はこちら」からメールが届き、再設定できる
- [ ] X のシェアボタンを押すと、正しい URL と紹介文が入る

## 4. 告知する

### どこに出すか

効果が出やすい順です。

1. **X(旧 Twitter)** — 「上司」「報連相」「言いにくい」で悩んでいる層に届きます。画像付きで投稿すると伸びやすい
2. **note** — 「なぜ作ったか」を書くと、アプリ単体より読まれます。作った経緯の物語があるほうが刺さる分野です
3. **知人への直接連絡** — いちばん確実。10人に個別で送るほうが、フォロワー100人への1投稿より使われます
4. **社会人向けのコミュニティ** — Slack や Discord の雑談チャンネルなど。宣伝が許されている場所かは事前に確認してください

### X の投稿文(案)

```
上司に言いにくいことを、どう伝えるか考えるのに毎回30分かけていたので、
アプリを作りました。

状況を書くと、その上司のタイプに合わせた言い方が3つ出ます。
「信頼にどう響くか」の予測つきです。

10月31日まで無料です。
https://(ドメイン)
```

### note の見出し(案)

- 「『これ、どう伝えよう…』で30分固まるのをやめたくて、アプリを作った」
- 「上司へのメールを書き直し続けた話と、その解決策」

### 知人に送る文(案)

```
言いにくいことを上司にどう伝えるか、というアプリを作ってみました。
よかったら試してもらえませんか。30秒で始められます。

https://(ドメイン)

使ってみて「分かりにくかったところ」を教えてもらえると助かります。
```

## 5. 公開後に見る数字

`docs/analytics.sql` を、**週に1回**実行してください。見るのは3つだけです。

| 見るもの | 何番 | 良い兆候 |
| --- | --- | --- |
| どこで人が止まっているか | 7番 | 登録した人の半分以上が相談まで進む |
| 2回以上使った人の割合 | 4番 | 3割を超える |
| 実績ベースの予測が出ているか | 5番 | 全体の1割を超える |

**4番が1割を切っていたら、集客より先に中身の見直しです。** 人を集めても穴の空いたバケツになります。

原価は1番で確認できます。想定(1日315円)を超えていたら `GLOBAL_DAILY_LIMIT` を下げてください。

---

## 6. 期限が来たら

`FREE_UNTIL` の日付までに、次のどれかを決めてアプリ内で告知します。

- **無料を継続** — 原価が月1,000円以内に収まっていて、まだデータを集めたい場合
- **有料に移行** — 2回以上使う人が3割を超えていて、続ける意思が見える場合。**Vercel を Pro($20/月)に上げる必要があります**(Hobby プランは商用利用が禁止されています)
- **提供を終了** — 使われていない場合。利用者のデータを削除し、その旨を告知します

いずれの場合も、期限を過ぎてから慌てないよう、**1週間前には決めておく**のが安全です。
