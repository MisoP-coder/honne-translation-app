# 無料公開の手順

無料公開のための、順番どおりの作業手順です。
アプリ側の準備(全体の上限)はコードに入っています。ここに残っているのは、Miso-P さんの手でしか進められないものです。

**期限は設けていません。**2026年9月30日までの予定でしたが、原価が累計55円にとどまったため、期限を切らずに無料で続けることにしました(→ 6章)。

---

## 1. 費用に蓋をする(公開前に必ず)

**ここを飛ばして公開しないでください。** 人が集まるほど請求が伸びる構造なので、二重に蓋をします。

### 1-1. Anthropic のクレジット上限

platform.claude.com の **Billing** で:

- **自動チャージ(Auto-reload)をオフ** にする
- クレジットを **$20 程度だけ** 入れる

これが最後の砦です。使い切ると候補の生成が止まりますが、それ以上は請求されません。

### 1-2. アプリ全体の1日上限

`lib/constants.js` の `GLOBAL_DAILY_LIMIT` で設定します(現在 **100回**)。

| 1日の上限 | 1日の原価 | 30日で |
| --- | --- | --- |
| 50回 | 約105円 | 約3,150円 |
| **100回**(現在の設定) | 約210円 | 約6,300円 |
| 150回 | 約315円 | 約9,500円 |

1回あたりの原価は実測 **約2.1円** です(claude-sonnet-5、150円/$換算)。
上限に達すると「本日はたくさんの方にご利用いただいたため、受付を終了しました」と表示され、日付が変わると戻ります。

> 予算に合わせて、この数字だけを変えてください。1-1 の $20(約3,000円)に対して 100回/日だと、毎日上限まで使われたとしても14日ほどもつ計算になります。

### 1-3. Supabase の無料枠

Supabase は無料プランのままで足ります。ただし **7日間まったくアクセスが無いとプロジェクトが一時停止** します。公開中は問題になりませんが、公開後に放置する場合は注意してください。

## 2. ドメインをつなぐ

取得済み: **`misop-craft.com`**(お名前.com)
アプリの URL: **`https://honne.misop-craft.com`**

`misop-craft.com` 自体は Miso-P さんの屋号として空けておき、アプリはその下のサブドメインに置きます。今後別のものを作っても並べられます。

### 2-1. Vercel にサブドメインを追加する

1. Vercel のプロジェクトを開き、URL の末尾に **`/settings/domains`** を足して直接開く
2. 入力欄に **`honne.misop-craft.com`** と入れて **Add**
3. 「Invalid Configuration」と赤く出ますが、正常です。DNS の設定がまだなので、次の手順で解決します
4. 画面に表示される **CNAME の値** を控える。このプロジェクトでは
   `d4e128e559ff7af4.vercel-dns-017.com` でした(プロジェクトごとに違います)

### 2-2. お名前.com で CNAME を登録する

お名前.com は画面が入り組んでいるので、順番どおりに。

1. お名前.com Navi にログイン
2. **ドメイン → DNS設定/転送設定 → DNSレコード設定を利用する**
3. `misop-craft.com` を選んで **次へ**
4. 「入力」の欄に、次のように入れる

   | 項目 | 入れる値 |
   | --- | --- |
   | ホスト名 | `honne` |
   | TYPE | `CNAME` |
   | VALUE | `d4e128e559ff7af4.vercel-dns-017.com` |
   | TTL | そのまま(3600) |

5. **追加** を押し、下にスクロールして **確認画面へ進む → 設定する**

> **ホスト名は `honne` だけ**です。`honne.misop-craft.com` と全部入れると `honne.misop-craft.com.misop-craft.com` になってしまいます。

> **末尾のドットは入れません。** Vercel は `...com.` と表示しますが、これは「完全なドメイン名」を示す DNS の記法です。お名前.com の入力欄はドット無しが前提のため、付けるとエラーになることがあります。

### 2-2b. うまくいかないときの確認

DNS を設定しても Vercel が `Invalid Configuration` のままなら、**ドメインのネームサーバーがお名前.com のものになっているか**を確認してください。

お名前.com Navi → **ドメイン → ネームサーバーの設定 → ネームサーバーの変更** で、`01.dnsv.jp` 〜 `04.dnsv.jp` が設定されていれば正常です。別のものになっていると、お名前.com の DNSレコード設定が無視されます。

### 2-3. 反映を待つ

お名前.com の DNS は反映に **数十分〜数時間** かかります(最大24時間)。
Vercel の Domains 画面が **Valid Configuration** に変わり、`https://honne.misop-craft.com` を開いて紹介ページが出れば完了です。

### 2-4. Supabase の URL を直す(いちばん大事)

**ここを忘れると、新しい URL でログインとパスワード再設定が動きません。**

Supabase の **Authentication → URL Configuration**(プロジェクト URL の末尾に `/auth/url-configuration`):

| 項目 | 値 |
| --- | --- |
| Site URL | `https://honne.misop-craft.com` |
| Redirect URLs | `https://honne.misop-craft.com/**` |

> 移行中は `vercel.app` のほうも残しておくと安全です。Redirect URLs は複数登録できます。

### 2-5. メール文面を日本語にする(任意)

ドメインがあれば、`docs/email-templates.md` の文面が使えるようになります。

1. [Resend](https://resend.com) に登録(無料枠 3,000通/月)
2. `misop-craft.com` を追加し、表示された DNS レコード(SPF・DKIM)をお名前.com に登録
3. Supabase の **Authentication → Emails → SMTP Settings** に Resend の情報を入れる
4. テンプレートのロックが外れるので、`docs/email-templates.md` の文面を貼る

告知には間に合わなくても構いません。**アプリ側で「英語のメールが届きます」と案内している**ので、後回しにしても利用者が詰まることはありません。

## 3. 公開前の最終確認

スマホの Chrome で、上から順に。**シークレットタブ**で試すと、初めて来た人と同じ状態を確認できます。

- [ ] `https://honne.misop-craft.com` を開くと紹介ページが出て、「登録も利用も無料です」が表示される
- [ ] 「無料ではじめる」→ 新規登録できる
- [ ] 上司を登録できる
- [ ] 候補が3案出る。冒頭に「送る前にご自身で読み直してください」が出ている
- [ ] 「この言い方を使った(結果はあとで記録する)」→ ホームに「結果待ち」が出る
- [ ] 結果待ちの「使った言い方を見る ▼」で文面が開く
- [ ] 3択を押すと実績が増える
- [ ] 同じ相手で結果を2件記録すると、実績ベースの予測に切り替わる
- [ ] `/privacy` と `/terms` が開き、運営者名と連絡先が出ている
- [ ] 「パスワードを忘れた方はこちら」からメールが届き、再設定できる
- [ ] X のシェアボタンを押すと、正しい URL と紹介文が入る

## 4. 告知する

### どこに出すか

効果が出やすい順です。

1. **X(旧 Twitter)** — 「上司」「報連相」「言いにくい」で悩んでいる層に届きます。画像付きで投稿すると伸びやすい
2. **note** — 「なぜ作ったか」を書くと、アプリ単体より読まれます。作った経緯の物語があるほうが刺さる分野です
3. **知人への直接連絡** — いちばん確実。10人に個別で送るほうが、フォロワー100人への1投稿より使われます
4. **社会人向けのコミュニティ** — Slack や Discord の雑談チャンネルなど。宣伝が許されている場所かは事前に確認してください

### X の投稿文(案)

```
上司に言いにくいことを、どう伝えるか考えるのに毎回30分かけていたので、
アプリを作りました。

状況を書くと、その上司のタイプに合わせた言い方が3つ出ます。
「信頼にどう響くか」の予測つきです。

無料で使えます。
https://honne.misop-craft.com
```

### note の見出し(案)

- 「『これ、どう伝えよう…』で30分固まるのをやめたくて、アプリを作った」
- 「上司へのメールを書き直し続けた話と、その解決策」

### 知人に送る文(案)

```
言いにくいことを上司にどう伝えるか、というアプリを作ってみました。
よかったら試してもらえませんか。30秒で始められます。

https://honne.misop-craft.com

使ってみて「分かりにくかったところ」を教えてもらえると助かります。
```

## 5. 公開後に見る数字

`docs/analytics.sql` を、**週に1回**実行してください。見るのは3つだけです。

**0番を実行すれば、下の全部が1枚で出ます。**週に1回はこれだけ見れば足ります。

| 見るもの | 良い兆候 |
| --- | --- |
| どこで人が止まっているか | 登録した人の半分以上が相談まで進む |
| 2回以上使った人の割合 | 3割を超える |
| 実績ベースの予測が出ているか | 全体の1割を超える |
| 直近7日の相談 | 0回になっていない |

**2回以上使った人が3割を切っていたら、集客より先に中身の見直しです。** 人を集めても穴の空いたバケツになります。

原価も0番に出ます。1日210円の想定を超えていたら `GLOBAL_DAILY_LIMIT` を下げてください。

## 6. 期限についての判断(2026年10月1日)

当初は2026年9月30日までの無料公開としていましたが、**期限を設けない**ことにしました。

判断の材料にした数字:

| 見たもの | 結果 |
| --- | --- |
| 累計の原価 | **55円**(公開から合計。1回あたり2.2円) |
| 登録した人 | 4人 |
| 結果の記録率 | 88% |
| 実績ベースの予測 | 52% |

ただし、**この4人はすべて運営者本人のアカウント**です。note と X で告知したあとも、外部の利用者は**0人**でした。記録率88%・実績ベース52%は「仕組みが動くこと」の確認にはなりますが、**他人に受け入れられた証拠ではありません。**

それでも期限を外したのは、原価が55円でやめる理由にならないからです。期限を切り直しても、利用者がいない状態で数か月後に同じ判断をやり直すだけになります。

**次に解くべき問題は、課金でも機能追加でもなく「誰にも知られていない」ことです。**

将来また判断が必要になるのは、次のどちらかが起きたときです。

- **原価が月1,000円を超えた** — まず `GLOBAL_DAILY_LIMIT` を下げる。それでも足りなければ有料化を検討する
- **3か月以上、誰も使っていない** — 提供の終了を検討する。利用者のデータを削除し、その旨を告知する

**有料に移行する場合は、Vercel を Pro($20/月)に上げる必要があります**(Hobby プランは商用利用が禁止されています)。今の原価の50倍以上かかるので、利用者が増えるまでは選択肢になりません。

利用規約には「有料への移行や提供の終了を行う場合は、事前にアプリ内でお知らせします」と書いてあります。この約束だけは守ってください。
