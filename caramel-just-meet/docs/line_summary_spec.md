# 要約の達人 〜上司の長文LINEを1文字で読め〜 仕様書

「極限！カラメル・ジャスト・ミート」と同じ Expo プロジェクト（`caramel-just-meet/`）に同居する、2 本目のバカゲー。
上から降ってくる上司の長文 LINE（おじさん構文）をよけながら、混ざっている【結論単語】だけを「要約カゴ」でキャッチする。

## 1. 画面の流れ

```
プリンのタイトル ──「📱 新作：LINEを要約する」──▶ 要約の達人タイトル ──「LINEを要約する」──▶ プレイ
        ▲                                              │   ▲                                  │
        └──────────────「🍮 プリンを遊ぶ」──────────────┘   └──「応答してタイトルへ」── 着信画面（ゲームオーバー）
                                                                    「拒否してもう一回」で即リトライ
```

- 起動時はこれまでどおりプリンのタイトル（公開中のプリンの遊び方は変えない）。
- ブラウザ版は `?game=line` を付けると「要約の達人」のタイトルから始まる。ゲームを切り替えると URL も書き換わる（再読み込みしても同じゲーム）。
- プリンとはハイスコア・BGM・効果音を分けている。音の設定（BGM / 効果音のオン・オフと音量）だけは共通。

## 2. ルール

| 項目 | 内容 |
| --- | --- |
| 操作 | 画面のどこでも左右にスワイプ → 指を動かした分だけ「要約カゴ」が動く（1.25 倍）。ブラウザは ← → / A D キーでも動く。Esc で一時停止 |
| 結論単語（キャッチ） | 明日休み・定時退社・ボーナス支給・有給承認・昇給・直帰OK・在宅OK・会議中止 |
| ゴミ（よける） | おじさん構文（長文の吹き出し、38 パターン）と、短い愚痴（昔は〜・説教・今から電話 など 10 種） |
| ライフ | 3。ゴミに当たると −1、0 でゲームオーバー |
| 得点 | 1 回 100 点 ＋ (連続数−1)×10 点。ブチギレ中は 2 倍 |
| コンボ | 結論単語を連続でキャッチした数。ゴミに当たる・結論単語を取り逃すと 0 に戻る |
| 難しさ | 落ちる速さは画面の高さ×(0.17 + 経過秒×0.0024)（90 秒で頭打ち）。降ってくる間隔は 1.1 秒 → 最短 0.5 秒 |
| 出現率 | 結論単語 38%／おじさん構文 約 42%／愚痴 約 20% |

当たり判定は見た目の箱そのもの。ただしゴミは左右を少し（最大 10px）内側にして、かすっただけで当たる理不尽さを減らしている。

### 必ずよけられるようにする

- ゴミの幅は「画面の幅 − カゴの幅 − 左右の余裕 14px ずつ」までにする（どんなに長いおじさん構文でも、横にカゴが通れる）。
- 降らせるとき、同じ高さにかかっているゴミ（カゴの高さぶん上下に広げて見る）と合わせて、カゴの幅＋28px の隙間が残る場所だけに置く。
  8 回探しても置けなければ、その回は降らせない。幅の広いものは左右どちらかの端に寄せて、反対側を空ける。
- ゴミは毎フレーム全部同じ速さで動かす（追い越して横に並び、隙間をふさがないように）。結論単語だけは少し遅く、別の速さで落ちる。

## 3. 上司の機嫌メーター（イライラ度ゲージ）

画面上部に「上司のイライラ度 0〜100%」のゲージと上司の顔（😊→😐→😤→😠→😡→🤬）を出す。色は緑 → 黄 → 橙 → 赤。

| できごと | イライラ度 |
| --- | --- |
| ゴミテキストをスルーして画面の下に消えた（＝既読スルー） | **+5%** |
| 結論単語をキャッチした（＝要約がうまくいった） | **−10%**（0% より下がらない） |

### 100% でブチギレ（デス・モード）

- 画面全体が赤く明滅し、「😡 上司がブチギレた‼️」のカットインが右から飛び込んでくる（約 1.7 秒）。
- **10 秒間**続く。ゲージは残り時間に合わせて減っていき、「あと ○.○ 秒耐えろ」と表示する。
- ブチギレ中は、おじさん構文と愚痴の**落下スピードが 2 倍**（結論単語の速さは変わらない）。
- 開始 1.4 秒後から 2.2 秒ごとに、特大ブロック **「今すぐ電話しろ‼️😡🔥」** が降ってくる。**当たると即ゲームオーバー**。
  ブロックは左右どちらかの端に寄せて降らせ、反対側にカゴが通れる隙間を残す。速さはブチギレ中のおじさん構文と同じ 2 倍速。
- ブチギレ中はイライラ度は動かない（キャッチしても下がらない）。代わりに得点は 2 倍。
- 10 秒耐え抜くと、イライラ度が **0%** に戻って通常モードへ。残っている「今すぐ電話しろ」ブロックは消え、「機嫌が直った！セーフ」と出る。

明滅の安全対策：光の点滅は 1 秒に 3 回を超えると発作を起こしやすいため、**1 秒に 2.5 回**に抑えている。
端末の「視差効果を減らす」がオンなら、点滅させずに一定の赤にし、画面の揺れや後光の回転も止める。

## 4. 演出

| 場面 | 演出 |
| --- | --- |
| タイトル | パチンコの大当たり風に 2 重の後光が逆向きに回る（14 秒で 1 回転）＋中心のスポットが明滅。「要約の達人」は極太の縁取り＋立体影の文字で、奥から 3 倍の大きさで「ドーン！」と飛び込み、その後は脈打つ |
| キャッチ | カゴが光ってつぶれ、「+120」が浮かぶ。「シャキーン！」の音はコンボで 5 段階に音程が上がる |
| コンボ（2 連続〜） | 「タイパ最高！」「有能！」「結論ファースト！」「神要約！」など 10 種のほめ言葉＋「○ COMBO!!」が、画面の奥から手前にバウンドして飛び出し、こちらに飛んでくるように消える。10 コンボ以上は虹色。3 コンボごとに脳汁音「キュインキュイン！」 |
| 被弾 | 「ブッブー」。画面が横に揺れ、カゴが赤くなって 💢 |
| ブチギレ | 「ドーン！」＋サイレン、赤い明滅、カットイン |
| ゲームオーバー | BGM がピタッと止まり、上司（部長）からの着信画面に。アバターがバイブのように震え、呼び出しの輪が広がる。音は着信のバイブ「ヴヴッ、ヴヴッ」→ 絶望の「チーン…」。結果（スコア・要約した数・最高コンボ・称号）を出し、赤の「拒否してもう一回」と緑の「応答してタイトルへ」で選ぶ |

称号（スコア順）：長文に溺れし者 → 行間読み見習い（800）→ 既読の達人（2000）→ 定時退社の申し子（4000）→ 社長室直通の要約マン（7000）→ 伝説の要約神（12000）

## 5. 絵文字の表示

- 降ってくるテキストは普通の `Text` で描き、絵文字はカラーのまま出す（`src/line/theme.ts` の `emojiText`）。
  - ブラウザ：日本語フォントのあとに Apple Color Emoji / Segoe UI Emoji / Noto Color Emoji を並べる（白黒の記号フォントで描かれないように）。
  - Android：上下の余白（includeFontPadding）を残し、行の高さを文字より大きめにとって、絵文字の頭が欠けないようにする。
- 縁取り文字（`OutlinedText`）は同じ文字を何枚も重ねて描くため、絵文字を入れると色付きの影が何重にも出てしまう。
  縁取り文字には絵文字を入れず、絵文字は横に普通の `Text` で並べる（例：カットインの「😡」「‼️」）。
- 吹き出しの大きさは、文字数から計算する（全角 1・半角 0.6・絵文字 1.25 文字分、絵文字をつなぐ記号は 0）。折り返しのずれに備えて 1 割大きめにとる。

## 6. BGM と効果音

すべて `scripts/generate_line_sounds.py` で波形から合成した自作の音で、アプリに同梱している（`assets/sounds/line/`）。
ネットの音源の直リンクは、リンク切れ・利用条件の確認・通信待ちで音がズレる心配があるので使わない。
差し替えたいときは、`src/line/sounds.ts` で `{ uri: 'https://…' }` を指定すれば URL の音も鳴らせる。

| ファイル | 用途 |
| --- | --- |
| line_bgm_title.wav | タイトル：大当たり風ファンファーレ＋四つ打ち（150 BPM） |
| line_bgm_game.wav | プレイ中：ハイテンポのユーロビート風（168 BPM） |
| line_catch_0〜4.wav | キャッチ「シャキーン！」（コンボで音程が上がる） |
| line_praise.wav | 3 コンボごとの脳汁音「キュインキュイン！」 |
| line_hit.wav | 被弾「ブッブー」 |
| line_rage.wav | ブチギレ「ドーン！」＋サイレン |
| line_calm.wav | ブチギレを耐え抜いた「ホッ…」 |
| line_gameover.wav | 着信のバイブ →「チーン…」 |

再生は expo-audio（Expo SDK 57 では expo-av が廃止されたため、プリンと同じ expo-audio を使う）。
プリンの `SoundManager` をそのまま使い、このゲーム専用のインスタンスを作る。

  sounds.ts                音の一覧と鳴らし方

  screens/LineTitleScreen.tsx

## 8. テスト（`__tests__/line.test.tsx`）

- おじさん構文が 20 パターン以上あり、そのうち絵文字入りが 20 以上
- キャッチでスコア加算・イライラ度 −10、スルーで +5、100% でブチギレ
- どの画面幅でも、ブチギレ中も、ゴミの横に必ずカゴが通れる隙間が残る
- ブチギレ中はおじさん構文だけ 2 倍速、「今すぐ電話しろ」で即ゲームオーバー、10 秒でゲージ 0% に戻る
- 明滅が 1 秒に 3 回未満であること
- プリン ⇄ 要約の達人 の行き来と BGM の切り替え、ゲームオーバーで着信画面とチーン
