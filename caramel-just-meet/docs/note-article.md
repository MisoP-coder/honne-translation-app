## 無料部分（ここから）

```
プリンの頂点に、カラメルを乗せる。それだけのゲームを作りました。

「極限！カラメル・ジャスト・ミート」
https://caramel.misop-craft.com

ぷるぷる揺れるプリンに向かって、タップでカラメルを落とします。頂点に乗ればセーフ、ど真ん中なら「JUST MEET!!」。ズレたら「ずるっ…」と滑り落ちて、即ゲームオーバーです。

連続で乗せるほど揺れが速くなり、10連続で集中線、20連続で画面が虹色に光ります。パチンコ台のような、無駄に壮大な演出が売りです。世界ランキングもあります。

まず1回遊んでみてください。30秒で終わります。


■ 作り方：パソコンなし、AI と会話するだけ

今回もスマホだけで作りました。コードは1行も自分で書いていません。

やったことは、AI（Claude）に日本語でお願いして、できたものをスマホで遊んで、気になったところを伝える。これの繰り返しです。

最初のお願いは、こんな感じでした。

・揺れるプリンの頂点にカラメルを落とすゲームを作って
・連続で乗せた数で、くだらない称号を付けて
・X でシェアできるようにして
・世界ランキングを付けて

そこから「もっとバカゲーっぽく」「プリンの見た目をこの画像みたいに」「BGM を付けて」「一時停止を付けて」と、遊んでは頼むを繰り返して、今の形になりました。

作り始めてから公開まで【要確認：○日】でした。


■ 使った道具と費用

・ゲーム本体：Expo（React Native）。スマホアプリにもブラウザ版にもできる
・世界ランキング：Supabase（無料プラン）
・サイトの置き場：Cloudflare Pages（無料プラン）
・ドメイン：前回取った misop-craft.com のサブドメイン（追加費用なし）
・タイトル画面の背景：Canva で作った絵を元に描き直し
・BGM・効果音：AI がプログラムで合成した自作の音（外部の音源は不使用）

月々の固定費は【要確認：費用】です。


■ AI に任せられたこと、任せられなかったこと

コードを書く、テストを書く、仕様書を書く。ここは全部 AI がやってくれました。テストは最終的に117個あり、変更のたびに自動で確認しています。

任せられなかったのは「遊んだ感想」です。

「当たり判定が狭い気がする。かなり難しい」
「トップ画面が地味な気がする」

逆に言うと、ここをサボると「動くけど面白くないもの」ができあがります。

## 有料部分（ここから先を有料に）

```
■ 1. 頼んだ道具が、もう存在しなかった

【症状】
BGM を付けるとき、「expo-av を使って、ネット上の著作権フリー音源の URL を直接読み込んで」とお願いしました。

【原因】
expo-av は、使っている Expo のバージョン（SDK 57）にはもう含まれていませんでした。後継の expo-audio に置き換わっています。
また、ネット上の音源を直接読み込むと、相手のサイトが止まったり URL が変わったりした瞬間に音が鳴らなくなります。著作権フリーの条件が変わる心配もあります。

【抜け方】
AI が expo-audio を使い、音は全部プログラムで合成した自作の音にしてくれました。ゲームの中に入っているので、どこかのサイトが止まっても鳴ります。

教訓：AI に道具を指定するときは「これを使って」より「これをしたい」で頼む。指定した道具が古いと、AI は理由を説明して別の道具を使ってくれます。


■ 2. ブラウザ版で、開いた直後に BGM が鳴らない

【症状】
スマホのアプリでは鳴るのに、ブラウザ版はタイトル画面の BGM が鳴りません。

【原因】
ブラウザは、ユーザーが画面に触れるまで音を出させてくれません（いきなり音が鳴る広告対策）。しかも iPhone の Safari は厳しく、「指が触れた瞬間」ではダメで、「指を離した瞬間」でないと音を出させてくれません。

【抜け方】
・指を離したとき（pointerup / touchend / click）に BGM を鳴らし直す
・1回目で失敗したときのために、タップのたびに試す
・鳴るまでは「画面をタップすると BGM が流れます」と表示する

教訓：「スマホで鳴る」と「ブラウザで鳴る」は別物。両方で確かめる。


■ 3. ブラウザを離れても BGM が鳴り続ける

【症状】
タイトル画面のままホームに戻ると、BGM がずっと流れ続けます。

【原因】
「アプリが裏に回ったら一時停止」の処理が、ゲーム画面にしかありませんでした。タイトル画面とランキング画面には、誰も止める人がいなかったのです。

【抜け方】
音を管理する部分そのものに「裏に回ったら全部止める、戻ったら続きから流す」を入れて、どの画面でも止まるようにしました。ブラウザでは visibilitychange と pagehide、アプリでは AppState を見ています。

教訓：「プレイ中」だけ確かめて終わりにしない。タイトル画面で放置してみる。


■ 4. 当たり判定が、見た目より狭かった

【症状】
遊んでいて「乗ったのに落ちた」と感じることが何度もありました。

【原因】
数字で調べると、セーフになる範囲が、見えているプリンの頂上の幅の75%しかありませんでした。端のほうに乗ると、見た目はセーフなのに判定はアウト。理不尽に感じて当然です。

【抜け方】
セーフの範囲を、見えている頂上の幅いっぱいに広げました。あわせて、ど真ん中判定を少し広げ、揺れが速くなるペースもゆるめました。
直す前に AI が「プリンが中央を通るとき、セーフになれる時間」を計算してくれて、最初は約0.8秒→約1.5秒、20連続で約0.4秒→約0.86秒になったと確かめてから出しています。

教訓：「難しい」という感想は、たいてい「理不尽」という意味。見た目と判定がズレていないかを最初に疑う。


■ 5. 低い画面で、タイトル画面が崩れる

【症状】
ブラウザ版のタイトル画面で、文字が詰まって重なりました。

【原因】
ブラウザはアドレスバーのぶん、アプリより画面が低くなります。全部を1画面に押し込もうとして、文字がつぶれていました。

【抜け方】
低い画面では、プリンと文字を少し小さくする「コンパクト表示」に切り替え、それでも入らなければスクロールできるようにしました。

教訓：自分のスマホだけで確かめない。ブラウザ版は特に、画面の高さが足りない前提で作る。


■ 6. 世界ランキングを「本物」にするときの守り

【症状】
最初はダミーのランキングでした。本物にするとき、誰でもデータを書き換えられる作りになるのが怖かった。

【原因】
ブラウザで動くゲームは、中身を誰でも見られます。データベースの鍵もブラウザに埋め込まれます。

【抜け方】
・データベースのテーブルは、直接は誰も読み書きできないようにする（RLS を有効にして、許可を1つも出さない）
・決めた3つの窓口（上位を取る・順位を調べる・記録を送る）からしか触れないようにする
・ゲームのルールで出せない点数は、サーバーで断る（点数の計算式から、ありえる点数かを判定）
・同じ人の送信は2秒に1回まで

それでも、ずるを完全に防ぐことはできません。極端な記録は手で消す、と割り切っています。

教訓：ブラウザに埋め込む鍵は「見られる前提」。守りはサーバー側に置く。


■ 7. Vercel で「Next.js が見つからない」と言われる

【症状】
デプロイしたら、次のエラーで止まりました。
「No Next.js version detected」

このゲームは Next.js を使っていません。

【原因】
2つ重なっていました。
・同じリポジトリの一番上に、前に作った本音翻訳アプリ（Next.js）があり、Vercel がそれに引っ張られて「Next.js のサイト」だと判定していた
・ゲーム用の設定ファイル（vercel.json）が、まだ main ブランチに入っていなかった

【抜け方】
・ゲーム用に、本音翻訳アプリとは別の Vercel プロジェクトを作る
・Root Directory をゲームのフォルダにする
・Framework Preset を「Other」にする
・設定ファイルを main にマージする

教訓：1つのリポジトリに2つ目のアプリを置くなら、公開先のプロジェクトも分ける。既存のプロジェクトの設定を書き換えると、前のアプリが壊れます。


■ 8. 独自ドメインで、ホスト名を全部入れてしまう罠

【症状】
caramel.misop-craft.com で開けるようにしたい。

【原因】
お名前.com の DNS 設定で、ホスト名に「caramel.misop-craft.com」と全部入れると、「caramel.misop-craft.com.misop-craft.com」になってしまいます（前回の本音翻訳アプリの手順書にも書いた、よくある罠です）。

【抜け方】
・ホスト名は「caramel」だけ
・値は、公開先の画面に表示された値をそのまま（末尾のドットは入れない）
・すでにある本音翻訳アプリやメールの設定は消さない

教訓：サブドメインを足すなら、既存のレコードには触らない。足すだけ。


■ 9. Canva の画像を、ゲームに取り込めなかった

【症状】
「デザイナー目線で、Canva でもっと面白そうな雰囲気に」とお願いしました。Canva で背景の絵はできたのに、ゲームに入れられません。

【原因】
AI が作業している環境から、Canva の画像ファイルをダウンロードできませんでした（ネットワークの制限）。

【抜け方】
Canva の絵を「見本」にして、同じ雰囲気をゲームの中で描き直してもらいました。結果的に、こちらのほうがよかったです。
・どの画面サイズでもくっきり
・放射線を回したり、紙吹雪をきらめかせたりできる
・ファイルが小さい

教訓：デザインツールは「完成品を作る場所」ではなく「方向を決める場所」として使うと、詰まらない。


■ 10. 無料プランのままでは、収益化できなかった

【症状】
ゲームが形になったので、広告や投げ銭で収益化しようとしました。

【原因】
Vercel の無料プラン（Hobby）は商用利用が禁止です。広告を置くのも、投げ銭のリンクを置くのも、商用にあたります。有料プランは月20ドル。今の規模では赤字です。

【抜け方】
無料で商用利用できる Cloudflare Pages に引っ越しました。このゲームはサーバーで動く部分がない静的なサイトなので、ビルドの設定を移すだけで済みます。独自ドメインもそのまま使えます。

教訓：無料プランは「何に使っていいか」まで読む。収益化を考えるなら、公開先は最初に決める。


■ おわりに

10個並べてみると、本音翻訳アプリのときと同じで、詰まったのはほとんど「コードの外側」でした。道具の世代交代、ブラウザの制限、公開先の設定、ドメイン、規約。

逆に、ゲームとして面白くなったのは、全部「遊んでみた感想」を伝えたときです。AI がコードを書いてくれる時代でも、遊ぶのは人間です。

ぜひ遊んで、世界ランキングに名前を残してください。
