# SNS運用会社

5人の AI 社員が分担して、X や note の投稿を作り、投稿後の数字から次の一手を決める仕組みです。
**スマホの Claude Code(claude.ai/code)から、このリポジトリを開いて1行打つだけ**で動きます。

## 社員

| 役職 | 社員名 | 仕事 | 書くファイル |
| --- | --- | --- | --- |
| 社長(進行役) | `/sns-company` | 依頼を受けて、5人に順番に仕事を渡す | `00-brief.md` |
| リサーチ担当 | `sns-researcher` | 読者の困りごと・伸びている投稿の型・時期の話題を、出典つきで調べる | `01-research.md` |
| 企画担当 | `sns-planner` | 狙い・読者・切り口・検証する仮説を決め、指示書にする | `02-plan.md` |
| ライター | `sns-writer` | 指示書どおりに投稿文を書く(書き出し2案つき) | `03-draft.md` |
| 編集担当 | `sns-editor` | 作り話・事実・文字数・ルールを校閲し、完成稿にするか差し戻す | `04-final.md` |
| 分析担当 | `sns-analyst` | 数字を記録し、仮説を検証して、学びを全員に共有する | `05-report.md` `metrics.md` `insights.md` |

## 仕事の流れ

```
Miso-P「先生への連絡で1本作って」
   │
   ▼
社長 ── 00-brief.md
   │
   ▼
リサーチ ── 01-research.md ◀──────────────┐
   │                                      │
   ▼                                      │ insights.md
企画 ── 02-plan.md ◀──────────────────────┤ (分かったこと・
   │                                      │  次に試すこと)
   ▼                                      │
ライター ── 03-draft.md ◀─┐ 差し戻し       │
   │                      │ (2回まで)     │
   ▼                      │               │
編集 ── 04-final.md ──────┘               │
   │                                      │
   ▼                                      │
Miso-P が投稿 → 数字を渡す                 │
   │                                      │
   ▼                                      │
分析 ── metrics.md / 05-report.md ─────────┘
```

分析担当が書いた `insights.md` を、次の案件でリサーチ担当と企画担当が最初に読みます。投稿するたびに、会社が自分のアカウントについて賢くなっていきます。

## 使い方

Claude Code で、次のどれかを打ちます。

| やりたいこと | 打つもの |
| --- | --- |
| 投稿を作る | `/sns-company 先生への連絡の場面で X を1本` |
| ゲームを広める | `/sns-company カラメルのゲームを子育て層に届けたい` |
| おまかせ | `/sns-company`(「次に試すこと」の1番目で作ります) |
| 数字を渡す | `/sns-company 振り返り 10/18の投稿 表示520 いいね8 RT2 返信1 ブクマ3` |
| 週に1回まとめて | `/sns-company 週次`(数字も一緒に貼る) |

完成稿はチャットに出ます。`【要確認】` の箇所を自分の実話に置き換えてから投稿してください。

## 守っていること

全員が `company.md` のルールに従います。いちばん大事なのは次の2つです。

- **作り話をしない。** 体験談・数字は Miso-P さんの実話だけ。分からないところは `【要確認】` で穴を空けて返します
- **投稿はしない。** AI 社員が作るのは下書きまで。外に出すのは Miso-P さんです

## ファイル

```
sns/
  README.md     この説明
  company.md    会社の前提・目標・ルール・文体(全員が最初に読む)
  metrics.md    投稿ごとの実測の台帳
  insights.md   分かったこと・次に試すこと
  projects/     案件ごとの作業フォルダ(00〜05 のファイル)

.claude/agents/sns-*.md          5人の社員の仕事の定義
.claude/skills/sns-company/      社長(進行役)の手順
```

社員の仕事の仕方を変えたいときは `.claude/agents/` の各ファイルを、会社の方針(読者・目標・ルール)を変えたいときは `company.md` を直してください。
