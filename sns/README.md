# SNS運用会社(X @papa_taito)

5人の AI 社員が分担して、X アカウント **@papa_taito** の運用全般を担う仕組みです。
週ごとの投稿計画、単発の投稿、返信・交流の下書き、プロフィールの見直し、数字の振り返りまでを行います。
**スマホの Claude Code(claude.ai/code)から、このリポジトリを開いて1行打つだけ**で動きます。

X には直接つながっていません。アカウントの情報や数字は、**スクリーンショットを貼って**渡します。

## 社員

| 役職 | 社員名 | 仕事 | 書くファイル |
| --- | --- | --- | --- |
| 社長(進行役) | `/sns-company` | 依頼を受けて、5人に順番に仕事を渡す | `00-brief.md` |
| リサーチ担当 | `sns-researcher` | 子育て層の実感・伸びている投稿の型・時期の話題・交流先の傾向を、出典つきで調べる | `01-research.md` |
| 企画担当 | `sns-planner` | 週の配分・題材・時間帯・検証する仮説を決め、指示書にする | `02-plan.md` |
| ライター | `sns-writer` | 投稿・返信・プロフィールの文章を書く(書き出し2案つき) | `03-draft.md` |
| 編集担当 | `sns-editor` | 作り話・家族の安全・文字数・ルールを校閲し、完成稿にするか差し戻す | `04-final.md` |
| 分析担当 | `sns-analyst` | 数字を記録し、仮説を検証して、学びを全員に共有する | `05-report.md` `metrics.md` `insights.md` |

## 仕事の流れ

```
本人「今週の投稿」        本人「ネタ: 〜があった」
   │                          │
   ▼                          ▼
社長 ── 00-brief.md        ideas.md(ネタ帳)──┐
   │                                          │
   ▼                                          │
リサーチ ── 01-research.md ◀──────────────────┤
   │                                          │
   ▼                                          │ insights.md
企画 ── 02-plan.md ◀──────────────────────────┤ (分かったこと・
   │                                          │  次に試すこと)
   ▼                                          │
ライター ── 03-draft.md ◀─┐ 差し戻し           │
   │                      │ (2回まで)         │
   ▼                      │                   │
編集 ── 04-final.md ──────┘                   │
   │                                          │
   ▼                                          │
本人が投稿 → 数字を渡す                        │
   │                                          │
   ▼                                          │
分析 ── metrics.md / 05-report.md ─────────────┘
```

## 使い方

| やりたいこと | 打つもの |
| --- | --- |
| 今週の投稿をまとめて作る | `/sns-company 今週` |
| 1本だけ作る | `/sns-company 運動会の朝の話で1本` |
| 返信・交流の下書き | `/sns-company 返信` |
| プロフィールを見直す | `/sns-company プロフィール` |
| 出来事をネタ帳に残す | `/sns-company ネタ 娘が初めて「パパがいい」と言った` |
| 数字を渡す | `/sns-company 振り返り` + アナリティクスのスクショ(撮り方は `metrics.md`) |
| 週に1回まとめて | `/sns-company 週次`(数字のスクリーンショットも一緒に) |

完成稿はチャットに出ます。`【要確認】` の箇所を自分の実話に置き換えてから投稿してください。

## 最初にやること

1. **`company.md` の「アカウントの中身」を埋める** — プロフィール文、よく投稿しているテーマ、書いてはいけないこと など。チャットで教えてもらえれば社長が書き込みます
2. **`ideas.md` にネタを3つ以上入れる** — 社員は作り話をしないので、ここが投稿の材料になります
3. `/sns-company 今週` で最初の週の投稿を作る

## 守っていること

全員が `company.md` のルールに従います。特に大事なのは次の4つです。

- **作り話をしない。** 体験談・数字は本人の実話だけ。分からないところは `【要確認】` で穴を空けて返します
- **家族を守る。** 子どもや配偶者が特定できる情報は書きません
- **雑多アカウント。** 子育て・Webアプリ開発中・無理しすぎない、の3つを軸に、何でもつぶやける形にしています(アプリの告知もOK)
- **X への操作はしない。** 投稿・いいね・フォロー・DM はすべて本人がします

## ファイル

```
sns/
  README.md     この説明
  company.md    アカウントの前提・方針・ルール・文体(全員が最初に読む)
  ideas.md      本人の実話のネタ帳
  metrics.md    投稿ごと・週ごとの実測の台帳
  insights.md   分かったこと・次に試すこと
  projects/     案件ごとの作業フォルダ(00〜05 のファイル)

.claude/agents/sns-*.md          5人の社員の仕事の定義
.claude/skills/sns-company/      社長(進行役)の手順
```

社員の仕事の仕方を変えたいときは `.claude/agents/` の各ファイルを、アカウントの方針(読者・目標・ルール)を変えたいときは `company.md` を直してください。
