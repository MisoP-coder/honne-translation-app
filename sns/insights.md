# 分かったこと・次に試すこと(@papa_taito)

分析担当が更新します。リサーチ担当と企画担当は、仕事の前に必ず読みます。
**確度**は「確か(複数回の実測で一貫)」「傾向(1〜2回の実測)」「仮説(未検証)」の3段階です。

最終更新: 2026-10-18(初期値。アプリ告知の3本しか記録がない)
