# 投稿の実測台帳(@papa_taito)

分析担当が管理します。**実測値だけ**を書きます(推測で埋めない)。
本人は、X のアナリティクスのスクリーンショットを `/sns-company 振り返り` と一緒に貼ってください(社長が書き起こします)。

### スクショの撮り方(スマホの X アプリ)

1. **投稿ごと** — 自分の投稿の下にある棒グラフのアイコンをタップ → 出てきた画面(表示回数・エンゲージメント・プロフィールへのアクセスなど)を撮る。投稿の書き出しが写るように
2. **アカウント全体** — プロフィール画面を撮る(フォロワー数が分かれば十分)
3. 撮るのは**投稿から2〜3日後**(数字がほぼ落ち着いてから)。週1回まとめてで構いません

- 反応率 = (いいね + RT + 返信 + ブックマーク) ÷ 表示
- プロフ閲覧・フォロー増は、X のアナリティクスで投稿ごとに分かる範囲で。分からなければ空欄
