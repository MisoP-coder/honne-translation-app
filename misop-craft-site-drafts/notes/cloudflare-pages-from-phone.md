# スマホだけで Cloudflare Pages に公開する（GitHub と連携できないとき）

ブラウザゲーム「極限！カラメル・ジャスト・ミート」を、Vercel から Cloudflare Pages に引っ越しました。広告を付けるためです（Vercel の無料プランは商用利用が禁止のため）。

パソコンは使わず、スマホの Chrome だけで作業しました。ところが、Cloudflare と GitHub をつなぐところで、どうしても先に進めませんでした。最終的には別の方法で公開できたので、その道筋をまとめます。

## 詰まったところ 1：GitHub でリポジトリが検索できない

Cloudflare の画面で「GitHub に接続」を押すと、GitHub 側で「どのリポジトリを Cloudflare に見せるか」を選ぶ画面になります。ここで「Only select repositories」を選んでリポジトリ名で検索しても、**「No repositories found.」と出て何も選べません。**

ログインしているアカウントは合っていました。

### 抜け方

Chrome の右上のメニューから **「PC 版サイト」にチェック**を入れて、ページを読み込み直したら、検索で出てくるようになりました。スマホ表示のときだけ、この検索欄がうまく動かないようです。

## 詰まったところ 2：許可したのに、Cloudflare に戻ると「GitHub に接続」のまま

GitHub 側の許可は終わっているのに、Cloudflare の画面に戻ると、ボタンは「GitHub に接続」のまま。リポジトリの一覧が出てきません。何度やり直しても同じでした。

### 原因（と思われるもの）

Cloudflare の「GitHub に接続」は、小さな別ウィンドウ（ポップアップ）で GitHub を開き、許可が終わったら元のページに知らせる仕組みです。スマホの Chrome は、ポップアップを止めたり、別のタブとして開いたりするので、この「知らせ」が元のページに届かないようです。

### 試したこと（どれもダメでした）

- Chrome の「PC 版サイト」に切り替える
- サイトの設定で、ポップアップを「許可」にする
- GitHub 側で Cloudflare のアプリをいったん削除して、入れ直す

## 最終的な方法：GitHub Actions から直接アップロードする

Cloudflare の画面で GitHub とつなぐのをあきらめて、**GitHub の側から Cloudflare にアップロードする**方法に切り替えました。GitHub Actions（GitHub が用意している自動実行の仕組み）に、次の流れを書きます。

1. main ブランチが更新されたら動く
2. テストを実行する
3. ゲームをビルドする
4. `wrangler pages deploy` で、できたファイルを Cloudflare Pages にアップロードする

この方法なら、ポップアップは一切出ません。スマホでやる作業は 2 つだけです。

1. Cloudflare で API トークン（合い鍵）を作る
   - プロフィール → API トークン → トークンを作成 → カスタム トークン
   - 権限は「アカウント / Cloudflare Pages / 編集」だけ
2. GitHub のリポジトリの Settings → Secrets and variables → Actions に、トークンとアカウント ID を登録する
   - アカウント ID は、Cloudflare のダッシュボードの URL の `dash.cloudflare.com/` の直後にある 32 文字の英数字

最初の実行で Pages のプロジェクトが自動で作られ、`○○.pages.dev` で開けるようになりました。あとは Cloudflare の画面でカスタムドメインを追加し、お名前.com の CNAME を書き換えて完了です（カスタムドメインの追加は、ポップアップなしでできました）。

## おまけ：初回はテストで落ちた

この仕組みの初回は、テストが 1 つ失敗して公開されませんでした。公開する URL を、テストを実行するときにも見える場所に書いていたせいで、「シェアの URL」を確かめるテストが想定と違う結果になったのが原因です。URL はビルドのときだけ渡すように直して解決しました。

逆に言えば、**テストが通らない限り公開されない**ので、壊れたものがそのまま世に出ることはありません。これは画面でつなぐ方法より安心だと感じました。

## まとめ

- スマホでつまずきやすいのは「別ウィンドウ（ポップアップ）」と「検索欄」
- 検索欄は、Chrome の「PC 版サイト」で動くことがある
- 画面での連携がどうしてもダメなら、GitHub Actions から `wrangler pages deploy` で直接アップロードする
- スマホでの作業は「API トークンを作る」「GitHub に登録する」の 2 つだけ
- テストを公開の前に入れておくと、壊れたまま公開されない
