# スマホのブラウザゲームで、BGM が鳴らない・止まらないとき

ブラウザで遊べるゲーム「極限！カラメル・ジャスト・ミート」に BGM を付けたら、スマホのブラウザで 2 つの問題が起きました。

- ゲームを開いた直後、BGM が鳴らない
- ホームに戻ったり別のタブに移ったりしても、BGM が鳴り続ける

どちらも、スマホアプリ版では起きませんでした。ブラウザならではの決まりが原因です。同じところで詰まる人のために、原因と直し方をまとめます。

## 1. 開いた直後に BGM が鳴らない

### 原因：ブラウザは「画面に触れるまで」音を出させてくれない

ブラウザには、ページを開いた瞬間にいきなり音が鳴らないようにする決まりがあります（自動再生の制限）。ユーザーが画面に触れるなどの操作をするまで、音を鳴らそうとしても失敗します。

さらに iPhone の Safari は厳しく、**指が触れた瞬間（touchstart / pointerdown）では許可されず、指を離した瞬間（touchend / pointerup / click）でないと許可されません。** 「触った瞬間に鳴らせばいい」と思って touchstart で再生すると、iPhone だけ鳴らない、ということが起きます。

### 直し方

1. BGM の再生を、**指を離したときのイベント**（pointerup・touchend・click・keydown）でやり直す
2. 1 回目でうまくいかなかったときのために、**タップのたびに再生を試す**（鳴っている最中に再生を頼んでも何も起きないので、何度呼んでも大丈夫）
3. 鳴るまでの間は「画面をタップすると BGM が流れます」と表示して、なぜ無音なのかを伝える

考え方だけを書くと、次のようになります。

```js
const unlock = () => {
  bgm.play().catch(() => {}); // 断られても、次のタップでまた試す
};
for (const type of ['pointerup', 'touchend', 'click', 'keydown']) {
  document.addEventListener(type, unlock, true);
}
```

注意点として、「ゲームオーバーでわざと止めた BGM」まで、タップで鳴らし直さないようにします。今どの曲を流したいのか（または流したくないのか）を覚えておいて、その曲だけを鳴らし直すのがコツです。

## 2. ブラウザを離れても BGM が鳴り続ける

### 原因：止める処理が、ゲーム画面にしかなかった

「アプリが裏に回ったら一時停止する」処理は作ってありました。ところが、それはゲームのプレイ画面の中にだけあって、タイトル画面やランキング画面にはありませんでした。タイトル画面のままホームに戻ると、誰も BGM を止めないので、ずっと鳴り続けます。

### 直し方

画面ごとに止めるのではなく、**音を管理する部分そのもの**に「裏に回ったら全部止める、戻ったら続きから流す」を入れました。こうすれば、どの画面にいても止まります。

ブラウザでは、次のイベントで「裏に回った」「戻ってきた」が分かります。

- `visibilitychange`：別のタブに移った・ホームに戻った・画面を消した（`document.visibilityState` が `hidden` になる）
- `pagehide` / `pageshow`：iPhone の Safari で、タブを閉じたり履歴を移動したりしたとき。`visibilitychange` が来ないことがあるので、念のため両方見る

```js
const sync = () => (document.visibilityState === 'hidden' ? pauseAll() : resume());
document.addEventListener('visibilitychange', sync);
window.addEventListener('pagehide', pauseAll);
window.addEventListener('pageshow', sync);
```

戻ってきたときの扱いにも気をつけました。

- BGM は、**頭からではなく止めたところから**流す
- プレイ中に離れた場合は、戻っても勝手に再開せず、一時停止の画面のままにする（いきなりゲームが動き出すと、気づかないうちにゲームオーバーになるため）
- 裏にいる間は、タップがあっても鳴らさない

## まとめ

- ブラウザの BGM は、**指を離したとき**に鳴らす。iPhone は特に厳しい
- 1 回で鳴らなくても、タップのたびに試す。鳴るまでは案内を出す
- 「裏に回ったら止める」は、画面ごとではなく音の管理の部分にまとめて入れる
- 戻ったら続きから。プレイ中なら一時停止のまま

ブラウザで動くゲームは「スマホアプリで動いたから大丈夫」とは限りません。タイトル画面で放置する、ホームに戻る、別のタブに移る、といった「プレイ以外の動き」も試してみるのがおすすめです。

【要確認】気づいたきっかけ（例：「ブラウザ版を開いたら無音で、壊れたのかと思った」など、あなたの実際の体験を一言入れると読みやすくなります）
