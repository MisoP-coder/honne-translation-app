# misop-craft.com 開発ノートの下書き

ここは **公開されない** 下書きの置き場です（GitHub Pages に公開されるのは `misop-craft-site/` だけ）。

## 目的

Google AdSense の審査で「有用性の低いコンテンツ」と言われたため、misop-craft.com に
「スマホと AI で Web アプリ・ゲームを作って公開したときの、実際に詰まったことと解決方法」を記事として増やす。

## 書き方の決まり

- **実際に起きたことだけを書く。** 作り話や、試していない方法は書かない
- **あなた（Miso-P）の言葉に直してから公開する。** AI が書いたまま大量に出すのは、Google のスパムポリシー（大量生成コンテンツ）に触れるおそれがある
- 【要確認】は、あなたにしか分からないこと（気持ち・日数・数字など）。書き換えるか消す
- 1 記事 1 テーマ。読んだ人が同じところで詰まらずに済むことをゴールにする

## 記事の候補（◎は下書きあり）

1. ◎ スマホのブラウザゲームで、BGM が鳴らない・止まらないとき（`notes/browser-game-bgm.md`）
2. ◎ 無料プランで「世界ランキング」を作るときの守り方（`notes/free-ranking-supabase.md`）
3. ◎ スマホだけで Cloudflare Pages に公開する（GitHub と連携できないとき）（`notes/cloudflare-pages-from-phone.md`）
4. ゲームの当たり判定は「見た目」に合わせる
5. お名前.com の DNS 設定で詰まったところ（サブドメイン・初期レコード）
6. 無料プランの「商用利用禁止」と、引っ越し先の選び方
7. Expo（React Native）で、スマホアプリとブラウザ版を同時に作る
8. 「言いにくいことの翻訳」を作ったきっかけと、使い方のコツ
9. AI に頼むときのコツ（「これを使って」より「これをしたい」）
10. AdSense の審査に落ちた理由と、やったこと（審査の結果が出てから）

## 公開の流れ

1. 下書きを読んで、直したいところを伝える（または自分で書き換える）
2. OK が出た記事から、Web ページにして `misop-craft-site/notes/` に置く
3. トップページに「開発ノート」の一覧を付ける
4. 記事が 10 本ほどそろったら、AdSense に再申請する
